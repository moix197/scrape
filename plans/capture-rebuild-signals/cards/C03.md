## Scope

`src/extract/structure.js` strips `<form>` subtrees from every section: `collectFormEls($, scopeEl)` (L417-419, `$(scopeEl).find('form').addBack('form').toArray()`) feeds `excludeAll` in `extractSectionContent` (L421-430), so form labels/buttons never pollute `text`/`links`/`images`/`headings`. That stays. But rebuilds then have no idea what the original contact form asked for.

After this card every section object produced by `buildSection` (L446-460) carries a new additive field:

```
form: { fields: [{ label, type, required }] } | null
```

- The **first** `<form>` returned by `collectFormEls` for the section; `null` when there is none.
- Field **values are never captured** (no `value` key, no option text, no defaults).
- Fields = `input, textarea, select` inside that form, in document order, skipping `input` whose `type` is one of `hidden`, `submit`, `button`, `reset`, `image`.
- `type` = the input's `type` attribute lowercased (default `'text'` when absent), or `'textarea'` / `'select'` for those elements.
- `label` resolution order: text of `<label for="<id>">` matching the control's `id` → text of a wrapping `<label>` (excluding the control's own text) → `placeholder` → `aria-label` → `name` → `''`. Trimmed and whitespace-collapsed.
- `required` = the control has a `required` attribute or `aria-required="true"`.
- Forms stay excluded from `text`/`links`/`images`/`headings` exactly as today (L421-430 exclusion unchanged) and a bare form outside any landmark still yields no section (the L205 test must pass unchanged).

Implementation (all in `src/extract/structure.js`, small single-purpose functions near `collectFormEls`):

- `isCapturableField(fieldEl)` — element is `input`/`textarea`/`select` and not one of the skipped input types.
- `resolveFieldLabel($, fieldEl)` — the label resolution chain above.
- `extractFormFields($, formEl)` — maps capturable controls to `{ label, type, required }`.
- `extractSectionForm($, sectionEl)` — takes `collectFormEls($, sectionEl)[0]`, returns `{ fields }` or `null`.
- Call from `extractSectionContent` so `buildSection` gains `form` immediately after `listItems` (or after `text` if C02 has not landed yet in the file — keep the new fields grouped together at the end of the content keys).

Fixture change in `test/fixtures/structure.html` — extend the existing contact `<form action="/submit">` (L57-71). Read the L193 form-strip test first and keep its existing targets (the link, img, button and heading it asserts are stripped) intact. Add:

```
<label>Email <input type="email" name="email" value="prefilled@example.com"></label>

```
