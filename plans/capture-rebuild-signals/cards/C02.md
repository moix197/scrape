## Scope

`extractSectionText` in `src/extract/structure.js` (L255-270) walks `.find('*').addBack()`, collects trimmed text nodes and returns `parts.join(' ')` — bullet lists are flattened into one run of prose, so rebuilds lose the list structure (service lists, feature bullets, steps).

After this card every section object produced by `buildSection` (L446-460) carries a new additive field:

```
listItems: [{ ordered: boolean, items: string[] }]
```

- One entry per **top-level** `<ul>`/`<ol>` inside the section. `ordered` is `true` for `<ol>`, `false` for `<ul>`.
- A list nested inside another list's `<li>` is NOT its own entry: its `<li>` texts are appended, in document order, as additional items of the enclosing top-level list — i.e. one flat `items` array per top-level list.
- Each item = that `<li>`'s own text nodes (excluding text belonging to a nested list), whitespace-collapsed and trimmed; empty items dropped.
- `[]` when the section has no lists.
- The flat `text` field is **unchanged** — it already contains list text via `extractSectionText` and must keep producing exactly the same string.
- Lists inside `<form>` or otherwise excluded subtrees are skipped (`excludeAll` from `extractSectionContent` L421-430 already includes form elements via `collectFormEls` L417-419).
- Nav sections get `listItems` too (uniform shape across all sections); `navTree` is unchanged.

Implementation (all in `src/extract/structure.js`, small single-purpose functions placed near `extractSectionText`):

- `collectListItemTexts($, listEl)` — returns the flat `string[]` for one top-level list, recursing into nested `ul/ol` inside each `<li>` and appending their items after the parent item's own text.
- `extractSectionListItems($, sectionEl, excludeAll)` — `.find('ul, ol').addBack('ul, ol')`, skipping lists that are `isExcluded($, el, excludeAll)` (L158) or that have an ancestor `ul`/`ol` within the section (check with `$(el).parents('ul, ol')` scoped so ancestors outside `sectionEl` don't count), mapping each remaining top-level list to `{ ordered, items }`.
- Wire into `extractSectionContent` (L421-430); `buildSection` gains `listItems` immediately after `text` in the object literal.

Fixture changes in `test/fixtures/structure.html`:

- In the about section add: `<ul><li>Fast turnaround</li><li>Fair pricing<ul><li>No hidden fees</li></ul></li><li>  Friendly   team </li></ul>`
- In the testimonials section add: `<ol><li>Step one</li><li>Step two</li></ol>`
- Inside the existing contact `<form action="/submit">` (L57-71) add: `<ul><li>form-only item</li></ul>` (must NOT appear in any section's `listItems`).
