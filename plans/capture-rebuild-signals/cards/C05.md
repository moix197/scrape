## Scope

Today `src/extract/copy.js` (15 lines) exposes `extractPageMeta(html)` (L10-15) returning only
`{ title, description }`, and `src/crawler.js` `processPage` (L121-145) stores them flat on the
page object (L138: `page: { url, title: meta.title, description: meta.description, structure }`).
Nothing about canonical URL, Open Graph, JSON-LD, `<html lang>` or the favicon reaches
`output/<domain>/`. The downstream rebuild needs all of them.

Observable after this lands, in `output/<domain>/structure.json`:

1. Every entry of `pages[]` gains a `meta` object (verbatim shape):

```
pages[].meta = {
  title,
  description,
  canonical,
  og: { title, description, image },
  jsonLd: [ <parsed objects> ]
}
```

2. A new top-level `site` object (verbatim shape):

```
structure.site = { lang, favicon }
```

`manifest.json` and `copy.md` stay **byte-identical** to a run before this card (apart from
timestamps) — the flat `page.title` / `page.description` used by `manifest.addPage` (scrapeSite.js
L225) and `buildCopyMarkdown` (L193-201) are left exactly where they are.

### Field rules

- `title`, `description`: exactly today's values (same trimming/fallback as the current
  `extractPageMeta`).
- `canonical`: `<link rel="canonical" href>` resolved to an absolute URL with `resolveUrl` from
  `src/utils/urls.js`; `null` when absent.
- `og.title`, `og.description`, `og.image`: from `<meta property="og:title|og:description|og:image" content>`;
  `og.image` resolved absolute via `resolveUrl`; each `null` when absent.
- `jsonLd`: every `<script type="application/ld+json">` body run through `JSON.parse`; invalid
  JSON is skipped silently; a top-level array is flattened one level into the result; `[]` when
  none.
- `site.lang`: `<html lang>` attribute of the **home** page, trimmed; `null` when absent.
- `site.favicon`: first `<link>` whose `rel` token list contains `icon` (`icon`,
  `shortcut icon`, `apple-touch-icon`), `href` resolved absolute; `null` when absent.
