## Scope

Today `src/render/playwrightFallback.js` (42 lines) launches and closes a fresh chromium on every call: `export async function renderWithPlaywright(url, { timeoutMs = 20000 } = {})` (L22-42) does `chromium.launch({ headless: true })`, opens a page, `goto`, `autoScrollPage(page)` (L13-20), and returns `await page.content()` as a bare string (`null` on any error, browser closed in `finally`). `loadPlaywright()` (L1-7) does a dynamic `import('playwright')` and returns `null` when the optional dependency is missing.

C07 (screenshots) and C08 (computed style) need a browser that outlives a single page and is shared with the crawler's render fallback, so this card introduces ONE reusable browser session per scrape run and makes `renderWithPlaywright` return an object. This is the plan's single allowed layer-only card: it is a prerequisite refactor with no new output file of its own — the observable effect is that a `--force-playwright` run launches chromium once instead of once per page, with byte-identical `structure.json`/`manifest.json`.

Design (implement exactly this):

1. `src/render/playwrightFallback.js` — add
   `export async function createBrowserSession({ timeoutMs = 20000, loadPlaywright: load = loadPlaywright } = {})`
   returning `{ available: boolean, withPage(url, { width, height }, fn), close() }`.
   - `available === false` (the loader returned `null`): `withPage(...)` resolves `null` without throwing; `close()` resolves.
   - When available: chromium is launched lazily on the first `withPage` (one `browser` per session). Each `withPage` opens a fresh `browser.newPage({ viewport: { width, height } })`, `page.goto(url, { waitUntil: 'networkidle', timeout: timeoutMs })`, `autoScrollPage(page)` (reuse L13-20 as-is), runs `fn(page)`, returns its result, closes the page in `finally`. Any error (goto timeout, `fn` throwing, ...) resolves `null` (mirrors today's null-on-error contract).
   - `close()` closes the browser if it was launched; no-op otherwise.
   - Keep every function at or under ~30 lines: split into `launchBrowser(load)`, `openPage(browser, viewport)`, `runOnPage(page, url, timeoutMs, fn)`.
2. Rewrite `renderWithPlaywright(url, { session, timeoutMs = 20000 } = {})` to
   `session.withPage(url, { width: 1280, height: 800 }, (page) => page.content())` and return `{ html }` on success or `null`. When no `session` is passed, create a throwaway session with `createBrowserSession({ timeoutMs })` and close it in `finally` (keeps any other caller working with the old one-arg call).
3. `src/crawler.js`:
   - `crawlSite(rootUrl, options)` (L155): add `browserSession` to the destructured options (L156-166) and to the deps object passed to `processPage` (~L189).
   - `processPage(url, deps)` (L121): pick `browserSession` from `deps` at L122 and pass it to `fetchPageHtml` at L123.
   - `fetchPageHtml(url, { userAgent, rateLimiter, onFetchLogged, minImagesThreshold, forcePlaywright, browserSession })` (L62-82): L77 becomes
     `const rendered = await renderWithPlaywright(url, { session: browserSession }); if (!rendered) return plainHtml;`
     and the html used afterwards is `rendered.html`. The log line at L80 (`method: 'playwright'`, `status: 200`) stays exactly as it is.
4. `src/scrapeSite.js` `runScrape(cliOptions)` (L334): create `const browserSession = await createBrowserSession();` before crawling, pass it as a 4th argument `crawlAndBuildManifest(cliOptions, manifest, fetchLog, browserSession)` (L213), which forwards `browserSession` in the `crawlSite(...)` options object (L214-222), and close it in a `try { ... } finally { await browserSession.close(); }` wrapping the rest of the run so the session is still open for C07/C08 after the crawl.
