## Scope

End-to-end verification that the whole plan delivers the settled outcome on the real reference
site. The orchestrator runs this card directly — **no subagent is dispatched**. Every step is a
human-in-the-loop check against `output/www.banksstudios.com/` and the read-only consumer repo
`C:\proyectos\web-express\templates\website_simple` (never modified).

## Files to touch

None. This card changes no files; it only runs commands and inspects output.

## Reuse first

- The automated suite: `pnpm test`.
- The existing CLI entry points: `pnpm scrape`, `pnpm restructure:export`, `pnpm restructure:apply`.
- The consumer repo's own test suite with its live-fixture env var.

## Acceptance criteria

- [ ] `pnpm test` is green in the worktree
- [ ] `pnpm scrape -- https://www.banksstudios.com/` exits `0`
- [ ] `output/www.banksstudios.com/structure.json`: top-level `contacts` is non-empty and every
      entry has `where: { page, sectionOrder }`; `site.lang` and `site.favicon` are set; every
      `pages[].meta.og` object is present; the contact page's section that carries the form has
      `form.fields` non-empty; at least one section has `listItems` non-empty
- [ ] `output/www.banksstudios.com/screenshots/index.json` has one entry for home plus one per
      nav page; each has `desktop` and `mobile` paths whose PNG files exist on disk and
      `error: null`
- [ ] `output/www.banksstudios.com/computed-style.json`: `site.colors` contains at least one
      non-grey accent (a hex that is not `#000000`, `#ffffff`, or a grey where r == g == b) and
      `site.fonts` is non-empty
- [ ] `output/www.banksstudios.com/fetch-log.jsonl` contains `"method":"screenshot"` lines — one
      per capture (2 per rendered page)
- [ ] `pnpm restructure:export www.banksstudios.com` then
      `pnpm restructure:apply www.banksstudios.com`: `structure.restructured.json` sections still
      carry `contacts`, `listItems`, `form`; pages carry `meta`; top-level `contacts` and `site`
      are intact
- [ ] In `C:\proyectos\web-express\templates\website_simple`:
      `SCRAPE_FIXTURE=C:/proyectos/web-express/scrape/output/www.banksstudios.com pnpm test`
      passes. If a pinned live-fixture test fails, determine whether the live site changed or an
      **existing** field value was altered by this plan — only the latter is a defect (new fields
      are additive and safe)
- [ ] Degrade check: make Playwright unavailable (temporarily rename `node_modules/playwright`,
      or run with `PLAYWRIGHT_BROWSERS_PATH=/nonexistent`), rescrape: exit code `0`,
      `screenshots/index.json` entries have `error` set, no PNGs written, every other output file
      unchanged; then restore Playwright
- [ ] README output table and `.ai/index.md` / `.ai/decisions/render-nav-pages-always-on.md`
      match the observed output files and field names
- [ ] No automated tests — justified because: this card runs the automated suite plus manual end-to-end checks
- [ ] Tests pass: `pnpm test`
- [ ] Documentation updated: `README.md`, `.ai/index.md` verified consistent with observed output
- [ ] Commit message references card id (e.g. `chore(scrape): final verification [#C10]`)

- **Manual check** — run in this order from the scrape worktree, `pnpm` only:
  1. `pnpm test`
  2. `pnpm scrape -- https://www.banksstudios.com/`
  3. Inspect `output/www.banksstudios.com/structure.json`, `screenshots/index.json`,
     `screenshots/*.png`, `computed-style.json`, `fetch-log.jsonl` against the criteria above
  4. `pnpm restructure:export www.banksstudios.com` then `pnpm restructure:apply www.banksstudios.com`;
     inspect `structure.restructured.json`
  5. `cd C:\proyectos\web-express\templates\website_simple` then
     `SCRAPE_FIXTURE=C:/proyectos/web-express/scrape/output/www.banksstudios.com pnpm test`
  6. Degrade run without Playwright, then restore
  7. Read README / `.ai/` against what step 3 showed
- **Review focus**
  - Existing field values unchanged (consumer pins them) — the single most likely regression
  - Every screenshot capture has a matching `"method":"screenshot"` fetch-log line (guardrail)
  - The degrade path exits `0` and leaves all non-render outputs identical
  - Round-trip through `restructure:apply` preserves every new field
